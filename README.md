# Freshdesk History Cleaner
Extension and userscript that hides history repeats in Freshdesk responses for cleaner reading.

# How to use
1. Go to a Freshdesk ticket page
2. Click on the 🧻 button on the left side to hide unecessary content from all the messages
3. Click on the ♻️ button on the left side to restore the original content️

## Settings

The extension popup includes these settings:

- **Skip first message**: Leaves the first ticket message unchanged while cleaning the others.
- **Default auto clean**: Enables cleaning automatically when a ticket loads.

## Userscript

The repository also includes a standalone userscript version for Tampermonkey, Greasemonkey, and compatible userscript managers. Install the userscript from the `userscript` folder to use the cleaner without installing the browser extension.

The userscript has the same settings available through your userscript manager's menu commands. Use the menu commands to toggle **Skip first message** and **Default auto clean**.
